#+TITLE: A100 YFCC NaviX Seed-Count Ablation Handoff
#+DATE: 2026-08-26

* Purpose

This experiment isolates why Recall@100 NaviX is stronger on YFCC-10M than Recall@10 NaviX.  Both
arms execute the same degree-64 SINGLE_CTA NaviX traversal, return =k=100= results, use
=max_queries=2048=, and include the bitmap prepass in search time.  The only changed variable is
the maximum number of passing bitmap seeds supplied to each query: 10 versus 100.

The seed cap is benchmark-only.  It does not modify cuVS's public API or NaviX's device traversal.
The host benchmark adapter allocates a =queries x seed_cap= seed matrix, the existing GPU prepass
fills up to that cap, and the existing SINGLE_CTA kernel consumes the reported stride.

* Search policy

The runner first measures the 10-seed B0 anchors =L in {128,256,512}= and =W in {1,2}=.  It then
binary-searches arbitrary integer L separately for each W until it resolves the target window
=[0.800,0.802]= or adjacent L values bracket it.  It adds the immediate neighbors of an in-window
point so the selection is not based on a lone sample.

Iteration depth is increased only if neither W reaches 0.800 at =L=512= with automatic B0
termination.  In that case only =L=512,W=2= is deepened, using bounded doubling followed by an
integer binary search, never exceeding 7,569 iterations.  The fastest measured point in the target
window is selected.  If the target is unreachable, the maximum-recall point and its QPS are kept.

The frozen 100-seed finalist (=L=100,W=1,I=56=) is rerun under the new binary.  Its recall must
exactly match the completed Recall@100 reference, and its QPS must remain within 15 percent.  A
1,000-query diagnostic capture for each arm reports actual seed count and bitmap words inspected.

* Prerequisites

Use the same full, non-MIG A100 80GB and data root as the completed Recall@100 run.  The reference
root must contain:

#+begin_src text

The data root must contain the prepared =navix_bitmap_k100/yfcc= correctness and throughput views,
the YFCC base vectors, and =cagra_g64_ig128.index=.

#+begin_src bash
cd /home/ubuntu/cuvs-filter

new =seed_cap < k= GPU test; performs the adaptive sweep; captures diagnostics; validates all
sentinel, predicate, and duplicate counters; and creates the compact bundle.

* Recovery

The result root is immutable.  Completed groups are validated and reused.  If a group is
interrupted, the runner identifies its exact =raw/GROUP/yfcc= directory and refuses to mix a
partial group with a rerun; remove only that named directory, then rerun =run.sh run=.  Do not
delete or replace the completed Recall@100 reference root.
