#+title: B0-first matched-recall GPU experiment

This pipeline measures CAGRA-Base, CAGRA-Retain, and CAGRA-NaviX at Recall@10 0.80 on
YFCC-10M and 0.95 on ArXiv-EM/EMIS/R. It uses the paper's resident per-query bitmaps, identity
source IDs, single-CTA search, k=10, max_queries=512, and complete cuVS-bench search-call timing.

Calibration uses one full 10,000-query repetition. It first evaluates max_iterations=0 (B0),
enumerates W in {1,2,4}, and refines L in 32-element units through the single-CTA maximum of 512.
Explicit continuation is considered only if no B0 point reaches the workload target. Calibration
QPS is never paper data. Up to three finalists are rerun for three repetitions.

Run everything with:

#+begin_src sh
cd /home/ubuntu/cuvs-filter-retrieve
export RETRIEVE_RESULT_ROOT=/home/ubuntu/retrieve_workshop_runs/matched_recall_$(date -u +%Y%m%d_%H%M%S)
benchmarks/retrieve_workshop/matched_recall/run_matched_recall.sh all
#+end_src

The final paper inputs are =analysis/final_summary.csv=, =analysis/selected_points.csv=, and
=analysis/provenance.json=. For YFCC, each repetition is five serial search calls and aggregate
QPS is =10000 / sum(shard_seconds)=. No recall interpolation is performed.
